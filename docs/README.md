# Allowance: Solana Hackathon Plan

An x402 spending firewall for AI agents on Solana, rebuilt from the Stellar project [Pay3](https://github.com/manasshete/PAYThreeWallet). A Solana program, not a server, enforces caps, expiry, merchant limits, reputation gates and a kill switch on every agent payment.
