# Overview and pitch

## Pitch

Build Allowance, a Solana successor to Pay3: an AI agent gets a small USDC allowance, and a Solana program, not your server, enforces the rules on every payment. You keep your main Phantom wallet. The agent holds only a session key that can spend from a program-owned vault within a per-payment cap, a daily cap, an expiry and an allowlist of recipients.

Why this wins: the judges want Solana doing real work, "not a chain bolted onto a web2 app." Here the chain is the security boundary. Even if the model or the MCP server is compromised, the program refuses anything outside the rules, and every payment settles in about a second for a fraction of a cent.

Target tracks: **Top 3 Overall** and the **AI Track** (agents that hold a wallet with spending limits is the first idea on the AI track's list).
